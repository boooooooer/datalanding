## 经典项目模式

| 项目 | 关键决策 |
|------|------|
| calibre | 自研 freezing(bypy)，嵌入 Python，`isportable` flag 检测文件夹 |
| draw.io Desktop | 默认离线(`MODE_DEVICE`)，云端功能需主动开启，`data/` 文件夹检测便携 |
| RStudio Desktop | R 运行时发现式(`RSTUDIO_WHICH_R`)，不嵌入 R，配置目录可重定向 |
| Tabby | `data/` 文件夹检测便携模式 |

## 四条铁律

1. **便携 = 文件夹检测**：`data/` 或 `portable/` 存在即自动切便携
2. **离线 = 默认状态**：断网不是"降级"，有网才是"增强"
3. **多进程 = 发现+健康检查**：不等死，不硬编码路径
4. **配置 = 相对路径**：删文件夹即卸载，不留注册表

## 现有 MolSuite 立即优化

不改框架的前提下，改 PyInstaller 参数可提速约 50%：

- `--onedir` 替代 `--onefile`（去掉自解压）
- `upx=False`（禁用 UPX 双重压缩）
- `excludes=['matplotlib','scipy','IPython','tkinter','PyQt5','PySide2']`
- `strip=True`（剥离调试符号）
- 减少 `_launch.py` 硬编码等待（`time.sleep(3)` → `time.sleep(1)`）

预估：MolEdit 冷启动 25-40s → 13-20s。
