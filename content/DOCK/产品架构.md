## 二、产品线架构

```
DataLanding 数达
  │
  ├── MolSuite              分子信息与互作计算
  │   └── 5 工具: CQ, PQ, PP, ME, MD
  │
  ├── tidyproteomics         质谱蛋白质组学数据处理
  │   └── 3 R包 + 3 桌面应用
  │
  └── PhenoAnalysis          表型分析
      └── PhenoECC
```

三条线独立迭代，通过 Bridge 协议点对点连接。交叉场景：ProteoLiP (LiP-MS 结构变化) → MD (3D 结构查看)。

## 三、技术架构

```
用户桌面
  │
  双击 启动.bat
  │
  ├─→ R Plumber (子进程) :8000
  │   └─ tidyproteomics / tidyLiP
  │
  ├─→ FastHTML + uvicorn :5001
  │   └─ htmx 前端 (无 JS 框架, 无 WebSocket)
  │
  └─→ 浏览器自动打开

打包: PyInstaller --onedir (开发) → Nuitka --standalone (生产)
分发: zip = Python embedded + R-portable + 应用代码
```

**MolSuite 架构：**

```
MD (母体, 退役中) — 原始单体应用
  │
  ├── CQ (ChemQuery)     化合物查询 → 独立 Streamlit 产品
  ├── PQ (ProtQuery)     蛋白查询   → 待建
  ├── PP (ProtPred)      口袋预测   → 独立 Streamlit 产品
  ├── ME (MolEdit)       分子编辑   → 独立 Streamlit 产品
  └── MD (MolInteract)   对接+动力学 → 重构中

共享: MolToolBank (Python 库)
通信: Bridge 协议
```

**tidyproteomics 架构：**

```
tidyproteomics (架构品牌, 不露面)
  │
  ├── R 包 (技术依赖)
  │   ├── TP    tidyproteomics → 统一数据处理
  │   ├── TLiP  tidyLiP        → LiP-MS 分析
  │   └── TTPP  tidyTPP        → 热蛋白质组分析 (待建)
  │
  └── 桌面应用 (FastHTML)
      ├── ProteoQuant → 定量+可视化合一
      ├── ProteoLiP  → LiP-MS 结构变化检测
      └── ProteoTPP  → 热蛋白质组学分析
```

## 四、架构决策记录

### D-001：三条线，一个伞品牌 ✅

MolSuite、tidyproteomics、PhenoAnalysis 共用 DataLanding 数达品牌，独立迭代。

### D-002：tidyproteomics 既是 R 包名也是产品线名 ✅

R 包：`library(tidyproteomics)`；桌面套件：ProteoQuant / ProteoLiP / ProteoTPP。UI 中标注 "Powered by tidyproteomics"。

### D-003：FastHTML 替代 Streamlit ✅

新工具全部 FastHTML。MolSuite (Streamlit) 按 CQ → PP → ME → MD 顺序迁移。

### D-004：离线优先 ✅

默认离线运行。网络功能（PDB 下载、PubChem 查询）作为可选的增强能力。

### D-005：便携模式 = 文件夹检测 ✅

`data/` 文件夹存在即触发便携模式，所有用户数据写入该目录。删文件夹即卸载。

### D-006：R 运行时发现式 ✅

启动顺序：扫描系统 R → 兜底捆绑 R-portable → 友好提示安装指引。

### D-007：三条线独立迭代 ✅

各自发布，互不阻塞，Bridge 协议点对点连接。
