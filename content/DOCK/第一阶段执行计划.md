## T4: R-portable + tpplumber

**执行位置**：本项目新建 `tpplumber/`

### 背景

tidyproteomics/tidyLiP 是 R 包。桌面工具通过 HTTP API 调用 R 计算。需要：
1. 一套可嵌入的 R API 端点
2. Python 侧的标准客户端

### 端点合约

统一响应格式：
```json
{
  "success": true,
  "data": {...},
  "error": null
}
```

| 端点 | 方法 | 功能 |
|------|:--:|------|
| `/read` | POST | 文件上传 → 列检测 → 返回 columns + n_rows |
| `/preprocess` | POST | normalize + impute + censor → 返回处理后的数据摘要 |
| `/quantify` | POST | 定量计算 → data_matrix + summary |
| `/compare` | POST | FC cutoff + p cutoff → n_up, n_down, comparison_table |
| `/recommend` | GET | 根据特征推荐最佳参数组合 |

### 任务

1. 创建 `tpplumber/` 目录结构：
   ```
   tpplumber/
   ├── api.R                ← 主入口, 启动 Plumber
   ├── helpers/
   │   ├── config.R          ← 配置 (端口, R-portable 路径)
   │   └── response.R        ← 统一响应封装
   ├── routers/
   │   ├── read.R
   │   ├── preprocess.R
   │   ├── quantify.R
   │   ├── compare.R
   │   └── recommend.R
   └── proteocore/           ← Python 客户端
       └── plumber_client.py
   ```

2. `plumber_client.py`：
   ```python
   class PlumberClient:
       def __init__(self, base_url="http://localhost:8000", timeout=120): ...
       def read(self, file_path) -> dict: ...
       def preprocess(self, **params) -> dict: ...
       def quantify(self, **params) -> dict: ...
       def compare(self, **params) -> dict: ...
       def recommend(self, features) -> dict: ...
   ```

### 验收标准

- [ ] `Rscript api.R` → Plumber 在 :8000 启动
- [ ] Python `PlumberClient().read("sample_data.csv")` 返回正确的 columns + n_rows
- [ ] 5 个端点全部可调通
- [ ] 错误响应格式一致（success=false + error 信息）

4-6h
