## 一、核心决策

### 为什么 FastHTML 而不是 Streamlit

Streamlit 的性能瓶颈是结构性的——Tornado + WebSocket + 前端 JS bundle 导致冷启动 5-8 秒，加上 PyInstaller `--onefile` 解压，MolEdit 实测首次启动 25-40 秒。

FastHTML（uvicorn + htmx）冷启动 < 1 秒。

**你的 MolSuite 打包慢的根本原因就是 Streamlit 本身**，不是 PyInstaller。技术细节和优化方案见 [TECHNICAL_DETAILS.md §一](./TECHNICAL_DETAILS.md#一问题诊断molsuite-为什么卡)。

### 分发哲学

不是"部署一个网站"，而是**"本地 Web 应用"**：

```
用户电脑上：
  双击 启动.bat → R Plumber 后台启动 → FastHTML 后台启动 → 浏览器自动打开
  一切在 localhost，零网络依赖
```

交付物是一个 zip 包（150-250MB），解压即用。分发渠道：U 盘 / 百度网盘 / 蓝奏云 / GitHub Releases。

## 二、架构

```
Python (FastHTML) — UI 层
    │  httpx
    ▼
R Plumber (子进程) — 统计计算层 (tidyproteomics / tidyLiP)

打包: PyInstaller (开发) → Nuitka (生产)
分发: zip = Python embedded + R-portable + 应用代码
```

### 目录结构

```
ProteoQuant/
├── app.py              ← FastHTML 主程序
├── _launch.py          ← 启动器: 启动 Plumber → FastHTML → 浏览器
├── 启动.bat            ← 用户双击入口
├── pages/              ← 页面路由
├── proteocore/         ← 共享组件库 (pip install -e .)
├── R-portable/         ← R 运行时 + tidyproteomics + plumber
├── proteoquant.spec    ← PyInstaller 配置
└── README.txt
```

详细配置（spec 文件、Nuitka 命令、R-portable 结构、启动器代码）见 [TECHNICAL_DETAILS.md](./TECHNICAL_DETAILS.md)。

## 五、立即可做：缓解 MolSuite 卡顿

不改框架的前提下，改 PyInstaller 配置即可提速约 50%（详见 [TECHNICAL_DETAILS.md §二](./TECHNICAL_DETAILS.md#二现有-molsuite-立即优化方案)）：
- `--onedir` 替代 `--onefile`
- `upx=False`
- 排除不必要模块（matplotlib, scipy, IPython, tkinter）
- 减少 `_launch.py` 硬编码等待时间

但 Streamlit 的 Tornado 启动那 5-8 秒省不掉——根治还是要换 FastHTML。
