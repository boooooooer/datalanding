## 四、核心差异

| | 数达 | 现有竞品 |
|------|------|------|
| 部署 | 解压 zip，双击即用 | 需安装/配环境/连服务器 |
| 网络 | 默认离线，有网可选增强 | 默认在线 |
| 价格 | 完全免费开源 | 商业软件年费数万 |
| 语言 | 中文界面 + 中文错误提示 | 几乎全是英文 |
| 门槛 | 零代码，无需节点连线 | 仍需学习工作流 |
| 领域 | 化学+蛋白质组学+表型 | 单一领域 |

## 五、技术架构

```
用户桌面
  │
  双击 启动.bat
  │
  ├─→ R Plumber (子进程) :8000
  │   └─ tidyproteomics / tidyLiP
  │
  ├─→ FastHTML + uvicorn :5001
  │   └─ htmx 前端
  │
  └─→ 浏览器自动打开

打包: PyInstaller (dev) → Nuitka (prod)
分发: zip = Python + R-portable + 应用代码
```
