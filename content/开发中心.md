## 🎯 第一阶段任务

```dataview
TABLE
  id as "编号",
  status as "状态",
  priority as "优先级",
  depends_on as "依赖",
  assigned_to as "执行方",
  estimated_hours as "预估(h)"
FROM "任务"
WHERE phase = 1
SORT
  status = "进行中" DESC,
  status = "阻塞" DESC,
  status = "待开始" DESC
```

> 依赖链：T1 → T2 | T3 独立 | T4 独立 | 全部完成后 → Phase 2
